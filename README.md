Projeto - Urna Eletrôniica

O projeto consiste no desenvolvimento de um sistema simples de votação, permitindo o cadastro dos participantes, 
o registro dos votos e a visualização da apuração dos resultados. 

O sistema é dividido em quatro páginas principais:

1. Cadastro de Candidatos
Página destinada ao cadastro dos candidatos que participarão da votação.
São registradas as informações necessárias para identificar cada candidato e disponibilizá-lo posteriormente na tela de votação.

2. Cadastro de Eleitores
Permite cadastrar os eleitores que estarão aptos a participar da votação.
O cadastro possibilita identificar cada eleitor e controlar o seu acesso ao processo de votação.

3. Votação
É a etapa em que o eleitor realiza seu voto.
Após sua identificação, o sistema apresenta os candidatos cadastrados para que seja feita a escolha.
O voto é então registrado no banco de dados, garantindo que a participação seja contabilizada.

4. Apuração dos Votos
Página responsável por apresentar o resultado da votação.
Os votos registrados são contabilizados e organizados por candidato, permitindo visualizar a quantidade de votos recebidos e identificar o resultado da eleição.

Tecnologias utilizadas:

1. Front-end:
  HTML, CSS e JavaScript

2. Back-end:
  PHP

3. Banco de dados:
  SQL

De

senvolver a estrutura inicial do sistema, integrando as páginas ao banco de dados e permitindo realizar o fluxo básico de cadastro → votação → registro → apuração.
